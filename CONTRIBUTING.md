# Contributing

Read `THRN_PROJECT_SPEC.md`, `AGENTS.md`, and `docs/ROADMAP.md` before proposing a change. Use one scoped branch (`feature/...`, `fix/...`) per task. Run `bash scripts/verify.sh` and submit a pull request against `main`. Keep CI green and do not merge until independent review accepts the stated criteria. Never commit secrets or execute untrusted downloaded skills.
