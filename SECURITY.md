# Security policy

THRN is under development and has no supported installer release. The current executable can fetch, install, update, list, and remove explicitly selected Codex project skills; support for a command does not establish publisher authenticity or guarantee safety of retrieved content. Review the [security model](docs/security-model.md) and repository verification status before relying on this build. Fixtures are synthetic and are not production skills.

Do not include credentials, unredacted private paths, or exploit payloads targeting real user environments in public reports. A repository security-advisory disclosure workflow has not yet been established; set one up before public launch.
