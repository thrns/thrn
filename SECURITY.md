# Security policy

This project is under development and has no supported release yet. Please do not use the bootstrap executable as an installer or use fixtures as production skills.

Do not post credentials, unredacted private paths, or exploit payloads targeting real user environments in public reports. For future public vulnerability disclosure, establish a repository security advisory workflow (GitHub Security Advisories) before launch.

Security promises: pinned public source revisions, bounded downloads, untrusted file/metadata validation, ownership receipts, no implicit script execution, recoverable state transitions, and refusal to overwrite user data without explicit authorization. None of these are implemented by the bootstrap stub.
