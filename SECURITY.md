# Security policy

THRN is under development and has no supported installer release. The current executable only parses commands and reports build metadata; it does not fetch skills or install files. See the [security model](docs/security-model.md) for the implemented boundary and the requirements planned for M1–M3. Do not use this build as an installer or treat fixtures as production skills.

Do not include credentials, unredacted private paths, or exploit payloads targeting real user environments in public reports. A repository security-advisory disclosure workflow has not yet been established; set one up before public launch.
